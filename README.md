# GitHub Trending Daily

## 만든 의미

GitHub Trending 저장소를 매일 모으고 README 기반 한국어 요약을 더해, 각 프로젝트의 목적과 사용법을 빠르게 파악하고 인기도 변화를 비교할 수 있도록 만든 대시보드입니다.

## 사용 방법

데이터는 GitHub Actions가 매일 오전 03:17(서울, Asia/Seoul)에 자동 갱신합니다. 사이트에서 전체·일간·주간·월간 기간과 프로그래밍 언어를 선택하거나 저장소를 검색할 수 있습니다. 카드에 마우스를 올리면 프로젝트의 목표·사용법·장단점을 확인할 수 있고, README 전체 보기와 즐겨찾기 기능을 사용할 수 있습니다. 현재 즐겨찾기는 사용 중인 브라우저에 저장됩니다.
