# GitHub Trending Daily

## Why It Was Made

This dashboard collects GitHub Trending repositories daily and adds Korean summaries based on their READMEs, making it easier to understand each project's purpose and usage and compare changes in popularity.

## How to Use

GitHub Actions refreshes the data automatically every day at 03:17 Asia/Seoul. Use the site to browse all, daily, weekly, or monthly results, filter by programming language, or search for a repository. Hover over a card to see the project's goals, usage, strengths, and limitations. You can also open the full README and save favorites. Signed-out favorites stay in the current browser; signing in with Google syncs them across browsers and devices using the same account.
