🐙 우리 사이트, 괜찮은가?

GitHub Trending Daily 점검 결과 — 아주 쉽게 풀어쓴 버전

🔍

💪 좋은 소리부터 기본 탄탄

우리 사이트는 이미 방어 잘 되는 집이에요. 잠금장치(Firestore 규칙), 현관 도어락(App Check), 오염 감지 센서(fail-closed 검증)까지 붙어 있거든요.

그런데… 집이 커졌는데 울타리는 그대로예요. 🏠→🏰

🚪 열린 문 3개 고치기 전에 위험

1️⃣ 남의 JS를 그냥 먹어요. CDN 스크립트에 신분증(SRI)도 없고, 출입 명단(CSP)도 없어요. 나쁜 놈이 끼어들면 사용자의 즐겨찾기를 마음대로 바꿀 수 있어요.

2️⃣ 자물쇠가 실패해도 조용히 무시돼요. Firebase 연결이 깨져도 에러 없이 그냥 열린 채로 둬요(보안 기능 꺼짐).

3️⃣ 두 군데 글자 검문 누락 — 언어·색상 값이 몸통 검사 없이 화면에 바로 들어가요.

😴 제일 큰 문제는 보안이 아니에요 숨은 위험

이 사이트의 심장은 "한국어 요약"인데, 이걸 만드는 기계(자동화)가 없어요. 매일 사람이 손으로 돌리고 있어요.

만약 2주만 손을 놓으면? 새 카드들이 전부 "저장소 문서 참조."라는 텅 빈 말만 남아요. 🫧

그리고 파이프라인이 삐걱거려도 아무한테도 알림이 안 와요. 조용히 오래된 데이터를 계속 보여주죠.

🤔 그래서 뭘 고치라고?

실험 3명(보안 해커 / 회의적 기획자 / 인수할 엔지니어)이 다 같이 골랐어요
